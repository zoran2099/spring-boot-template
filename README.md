# spring-boot-template

Template base para criação de serviços Spring Boot.

## Stack

- Java
- Spring Boot
- Maven Wrapper (`mvnw`)

## Estrutura principal

- `src/` — código-fonte e testes
- `pom.xml` — configuração Maven
- `docs/` — documentação de apoio
- `.devcontainer/` — ambiente de desenvolvimento

## Como executar

```bash
./mvnw spring-boot:run
```

## Como testar

```bash
./mvnw test
```

## Objetivo

Acelerar a criação de novos serviços com padrão consistente de estrutura e build.
